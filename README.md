# Second Look

Evidence-grounded, multilingual AI for investigating suspicious messages and helping people verify before they trust.

## Planned components

- ML: supervised message classification and evaluation
- RAG: hybrid retrieval over trusted fraud guidance
- Backend: FastAPI
- Frontend: Next.js
- Languages: English, Hindi, Telugu, Urdu, and Bengali, subject to evaluation

## Principles

- Ground conclusions in traceable evidence.
- Communicate uncertainty honestly.
- Never treat a model prediction as proof of fraud.
- Never expose secrets or private data.
- Evaluate performance on held-out examples.

## Status

Early development. Model selection, datasets, and evaluation results are not yet finalized.
